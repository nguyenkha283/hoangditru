Thêm nút "YouTube" vào Classic Editor (TinyMCE). Dán link YouTube để chèn video responsive vào nội dung qua shortcode [youtube_embed].

== Cài đặt ==
1. Copy thư mục `snera-youtube-embed` vào `wp-content/plugins/` (hoặc upload file .zip qua Plugins > Add New > Upload).
2. Kích hoạt plugin trong Plugins.
3. Mở bài viết/trang ở Classic Editor, bấm nút "YouTube" trên thanh công cụ, dán link, bấm "Chèn".

== Ghi chú ==
- Video được lưu dưới dạng shortcode: [youtube_embed url="https://www.youtube.com/watch?v=XXXXXXXXXXX"].
- Hỗ trợ các định dạng link: watch?v=, youtu.be, /embed/, /shorts/, hoặc ID thuần.
- Dùng youtube-nocookie.com để hạn chế cookie theo dõi.
- Cần plugin Classic Editor (hoặc block "Classic") nếu site đang dùng Gutenberg.
